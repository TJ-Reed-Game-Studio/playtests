TJs Game Studio rclone

A private file copy tool for one person's own Google Drive.

TJs Game Studio rclone is the Google sign-in for rclone, the open source file sync program, as it runs on one computer: the studio owner's own Mac. The studio uses it to copy its large working files, such as game trailer masters, into a folder in the owner's own Google Drive, and to fetch them back.

Who it is for

Only the studio owner. It is not offered to anyone else, has no other users, and asks no one else to sign in.

What it does with Google Drive

  • Lists, uploads and downloads files in the owner's own Drive, in the studio's folder.
  • Runs only on the owner's computer. Files go straight between that computer and Google Drive.
  • Sends nothing to any other server, and shares nothing with anyone.
