Privacy policy

TJs Game Studio rclone. Last updated November 17, 2026.

TJs Game Studio rclone is the Google sign-in for the rclone file sync program on the studio owner's own computer (what the app is). Its only user is the studio owner, and the only Google account it reaches is the owner's own.

What it accesses

With the owner's consent, it has full access to the owner's own Google Drive (Google's drive scope), which rclone needs to list, upload and download files. In practice it copies the studio's working files into the studio's folder there and back. It asks for no other Google data.

Where data goes

  • Files move only between the owner's computer and the owner's Google Drive.
  • The sign-in token is stored only in rclone's settings file on that computer.
  • The app has no server of its own. It collects, keeps, sells and shares no data, and sends none to the studio, to advertisers or to anyone else.

Retention and deletion

The app keeps nothing of its own. Files stay in the owner's Drive until the owner deletes them, and the token stays on the owner's computer until access is removed (below), which deletes it.

Google API Services User Data Policy

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

The owner can remove the app's access at any time from Google Account, Third-party apps and services, and delete the token by removing the Drive remote from rclone.
